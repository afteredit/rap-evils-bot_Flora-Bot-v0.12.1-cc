# Flora Bot — نسخهٔ ۰.۱۴ (داشبورد مدیریت دکمه‌محور)

این نسخه مدیریت ربات را از «مجموعه‌ای از دستورات» به یک **داشبورد مرحله‌ای** تبدیل می‌کند.
اصل حاکم: **مدیر برای هیچ‌کدام از کارهای معمول مقدار فنی، دستور یا متن انگلیسی وارد نمی‌کند.**

- منوی اصلی از ۲۴ دکمه به **۸ دسته** کاهش یافت.
- همه‌چیز با دکمه، منوی انتخابی، کلید روشن/خاموش، تأیید نهایی و صفحه‌بندی انجام می‌شود.
- مقادیر داخلی مثل `true` / `false` / `auto` / `approval` / `classic` **فقط در شیت** ذخیره می‌شوند و
  هرگز به مدیر نشان داده نمی‌شوند؛ مدیر «انتشار خودکار / تأیید مدیر» یا «روشن / خاموش» می‌بیند.
- ساختار Google Apps Script + Google Sheets، نشست‌ها، کنترل دسترسی مدیران و داده‌های موجود **دست‌نخورده** ماندند؛
  هیچ تغییر اجباری در ساختار شیت‌ها لازم نیست.

---

## ۱) منوی اصلی: ۸ دسته

| دسته | دسترسی لازم | داخل آن |
|---|---|---|
| 🎵 مدیریت موزیک | `submissions` | دسته‌بندی جدید/در انتظار/صف/منتشر/ناموفق/ردشده/Coming Soon/فری‌استایل، کارت هر اثر، تأیید گروهی، تلاش دوبارهٔ گروهی |
| 📡 کانال‌ها | `channel` | کانال اصلی و ثانویه، قالب هر کانال، رایگان/VIP، تست اتصال، کانال آزمایشی، کانال‌های وصل‌شدهٔ هنرمندان |
| 👥 کاربران | `users` | فهرست و جست‌وجو، مسدود/فعال، درخواست بازیابی رمز، مدیران و نقش‌ها، خروجی CSV |
| 💎 اشتراک و پرداخت | `settings` | پلن‌ها، ساخت پلن با دکمه، درخواست‌های پرداخت، تأیید/رد، کاربران VIP، تمدید، افزایش سهمیه، اهدای اشتراک، تاریخچه |
| 📣 تبلیغات و پیام‌رسانی | `broadcast` | کمپین جدید، همهٔ کمپین‌ها، کمپین غیرفعال‌ها، بنر تبلیغاتی، کانال‌های وصل‌شده |
| 💬 پشتیبانی | `support` | پیام‌های خوانده‌نشده، همهٔ گفت‌وگوها، بستن گروهی گفت‌وگوها |
| 📊 آمار و گزارش | `settings` | آمار کلی، داشبورد هنرمندان، آمار ترک‌ها، تقویم انتشار، خروجی CSV، تاریخچهٔ تغییرات، خطاها |
| ⚙️ تنظیمات سیستم | `settings` | مرکز تنظیمات هوشمند، وضعیت بات، عضویت اجباری، ظاهر، نگهداری/بکاپ، توقف اضطراری، حالت آزمایشی |

«📚 آثار من» از منوی مدیر برداشته شد؛ مدیر برای بررسی کارِ دیگران از «🎵 مدیریت موزیک» استفاده می‌کند.
دکمه‌های کیبورد قدیمی همچنان کار می‌کنند تا کیبوردِ ذخیره‌شده در چت مدیر نشکند، ولی به همان پنل‌های جدید می‌رسند.

## ۲) مرکز تنظیمات هوشمند

مسیر: **⚙️ تنظیمات سیستم → 🧠 مرکز تنظیمات هوشمند** (یا از کارت داشبورد)

گروه‌ها (هر کلید به‌صورت دکمه/انتخاب‌گر فارسی):

- 🚀 **انتشار و صف** — پردازش انتشار، حالت انتشار (انتشار خودکار / تأیید مدیر)، پردازش صف،
  فاصلهٔ انتشار (۱/۵/۱۰/۱۵/۳۰/۶۰ دقیقه)، منطقهٔ زمانی، انتشار چندکاناله، انتخاب کانال مقصد،
  مقصد پیش‌فرض ارسال‌ها، فوتر پست.
- 🚦 **وضعیت و زبان بات** — فعال / توقف موقت / تعمیرات، زبان پیش‌فرض، تغییر زبان توسط کاربر.
- 🎵 **موزیک و دانلود** — دانلود پیش‌فرض، حذف فایل دانلود بعد از ۳۰/۶۰/۱۲۰/۳۰۰ ثانیه، طول برش پیش‌نمایش،
  محل برش (اوج/ابتدای اثر/جای پیش‌فرض)، دکمهٔ دانلود روی کاور و متن آن، دکمه‌های لینک، الزام لینک هنرمند،
  سقف ارسال روزانه، سقف فایل صوتی و حجم، تعداد آیتم هر صفحه.
- 🎨 **ظاهر و دکمه‌ها** — رنگ دکمه‌های معمولی/شیشه‌ای/حساس، پاسخ صوتی به کاور، محتوای محافظت‌شده، نام برند.
- 💎 **اشتراک و پرداخت** — روشن/خاموش بودن VIP، قالب VIP خودکار، تأیید خودکار پرداخت،
  سهمیه و مدت پیش‌فرض VIP، شمارهٔ کارت، نام صاحب کارت، توضیح پرداخت.
- 📡 **کانال‌ها و قالب‌ها** — کانال اصلی، یوزرنیم ربات، کانال آزمایشی، قالب و دسترسی کانال اصلی،
  حالت/سقف اتصال کانال هنرمند، بنر خودکار، پیام معرفی، تبلیغ کانال هنرمند.
- 🔔 **اعلان‌ها** — اعلان ارسال جدید، اعلان پرداخت جدید، اعلان خطای انتشار، اعلان خطای عمومی،
  آستانه و تکرار پیام کاربران غیرفعال.
- 🌐 **عضویت اجباری** — وضعیت و فهرست کانال‌های عضویت اجباری (با افزودن کانال راهنمادار).
- 📝 **متن‌ها و قالب پست** — خوش‌آمد، تعمیرات، پایان ثبت‌نام، عضویت اجباری، نیاز به VIP،
  متن انتظار/صف، پیام غیرفعال‌ها، پایان گفت‌وگو، برچسب‌های پست، نشان VIP، هشتگ برند و نوع ارسال،
  ژانرها، پلتفرم‌های لینک هنرمند (همراه متن‌های انگلیسی).
- 🧹 **نگهداری و امنیت** — بکاپ خودکار و نام پوشه، حذف پیش‌نویس کهنه، فاصلهٔ پاک‌سازی، عمر نشست، اعتبار ورود.
- 🛠 **پیشرفته و فنی** — سهمیه‌های نرخ، کاورها، سیاست جایگزین پیش‌نمایش، پارامترهای تحلیل صدا و کلیدهای امنیتی.
  علاوه بر این‌ها، «🧾 فهرست فنی همهٔ تنظیمات» برای موارد نادر باقی مانده است.

**رفتار استاندارد هر تنظیم:** مقدار فعلی روی دکمه نوشته می‌شود، گزینهٔ انتخاب‌شده با «✅» مشخص است،
کلیدهای دوحالته تیک 🟢/⚪️ دارند، و برای تنظیم‌های متنی همان مقدار فعلی بالای صفحه نمایش داده می‌شود
(با راهنما، اعتبارسنجی و دکمهٔ «❌ لغو»). بعد از هر تغییر، به همان گروه فارسی برمی‌گردد — نه به فهرست فنی.

## ۳) مدیریت موزیک

- **دسته‌بندی:** 🆕 جدید · ⏳ منتظر تأیید · 🗓 صف انتشار · ✅ منتشرشده · ⚠️ ناموفق · ❌ ردشده ·
  ⏳ Coming Soon · 🎤 فری‌استایل — همه با شمارنده و صفحه‌بندی (۸ اثر در هر صفحه).
- **کارت اثر:** نام، هنرمند، وضعیت، شناسه، زمان، مالک، کانال‌های مقصد، قالب، وضعیت دانلود، خطا/یادداشت.
  دکمه‌ها بر اساس وضعیت: ✅ تأیید و انتشار · ❌ رد · 🚀 انتشار نهایی · 🗓 زمان انتشار · 🔁 تلاش دوباره ·
  ⏹ توقف · 👁 پیش‌نمایش پست · 📂 فایل‌های هنرمند · 📡 تغییر کانال · 🎨 تغییر قالب ·
  ✏️ ویرایش اطلاعات · ⬇️ مدیریت دانلود · 🗑 حذف (با تأیید دوباره).
- **پیش‌نمایش پیش از انتشار:** دکمهٔ «🚀 انتشار نهایی» ابتدا صفحهٔ تأیید با فهرست مقصد و قالب نشان می‌دهد؛
  در آن صفحه هم «👁 پیش‌نمایش پست» و هم «✅ انتشار نهایی» هست. انتشار بدون تأیید انجام نمی‌شود.
- **زمان انتشار:** گزینه‌های آماده (۳۰ دقیقه، ۱ ساعت، ۳ ساعت، ۱ روز، همین حالا) + ورودی زمان دلخواه.
- **قالب:** انتخاب از ۵ قالب؛ روی همهٔ کانال‌های همان اثر اعمال می‌شود و در `SubmissionChannels` ثبت می‌گردد.
- **تأیید گروهی:** انتخاب چند اثر با چک‌باکس (⬜️/✅) و سپس «✅ تأیید انتخاب‌شده‌ها».
- **تلاش دوبارهٔ گروهی:** برای همهٔ آثار ناموفق (تا ۲۰ مورد در هر اجرا).

## ۴) کانال‌ها

- فهرست همهٔ کانال‌های فعال با برچسب قالب و رایگان/«نیازمند VIP»؛ کارت هر کانال همان پنل قبلی است
  (قالب، دسترسی، فوتر، فعال/غیرفعال، حذف با تأیید دوباره، پیش‌نمایش قالب).
- **🧪 تست اتصال و پیش‌نمایش:** متن قالب هر کانال فقط در چت مدیر ارسال می‌شود؛ هیچ‌چیز در کانال منتشر نمی‌شود.
- **🎛 حالت آزمایشی:** تعیین/حذف کانال آزمایشی (`STAGING_CHANNEL_ID`) برای دیدن نتیجهٔ واقعی بدون انتشار عمومی.

## ۵) اشتراک و پرداخت

- **ساخت پلن با دکمه:** مدت (۷/۳۰/۹۰/۱۸۰/۳۶۵ روز) → سهمیه (۱/۳/۵/۱۰/۳۰ ترک) → نشان (💎🥇🥈🥉🔥) →
  قیمت (دکمه‌های آماده یا ورودی عددی) → «✅ ساخت پلن». نام پلن اگر وارد نشود خودکار ساخته می‌شود.
  روش ورود یک‌خطی قدیمی هم برای مدیران حرفه‌ای باقی مانده است.
- **ویرایش پلن** (قیمت/مدت/سهمیه/نشان) با دکمه‌های آماده و مقدار فعلی.
- **درخواست‌های پرداخت:** فهرست، جزئیات، رسید، ✅ تأیید، ❌ رد با دلیل.
- **تمدید اشتراک:** آیدی هنرمند → انتخاب ۷/۳۰/۹۰ روز؛ از تاریخ انقضای فعلی (یا امروز، هرکدام دیرتر) محاسبه می‌شود.
- **افزایش سهمیه:** آیدی هنرمند → +۱/+۳/+۵/+۱۰ ترک.
- **اهدا/لغو اشتراک، تاریخچهٔ پرداخت و اشتراک، اطلاع‌رسانی خودکار به هنرمند.**

## ۶) قابلیت‌های تازهٔ این نسخه

| قابلیت | جای آن |
|---|---|
| 🔔 اعلان مدیریتی (ارسال/پرداخت/خطای انتشار) | مرکز تنظیمات → 🔔 اعلان‌ها |
| 🧾 تأیید گروهی | مدیریت موزیک → 🧾 تأیید گروهی |
| 👁 پیش‌نمایش پست قبل از انتشار | کارت اثر و صفحهٔ تأیید انتشار |
| 🔄 انتشار مجدد و تلاش دوبارهٔ گروهی | کارت اثر / هاب موزیک |
| 📅 تقویم انتشار | آمار و گزارش → 📅 تقویم انتشار |
| 🧑‍💼 نقش‌های دقیق مدیران | کاربران → 🛡 مدیران و نقش‌ها (نقش با دکمه انتخاب می‌شود) |
| 📜 تاریخچهٔ تغییرات | آمار/تنظیمات سیستم → تاریخچهٔ تغییرات مدیران |
| 🔍 جست‌وجوی یکپارچه (اثر/کاربر/پرداخت/شناسه) | کارت داشبورد |
| 🛑 توقف اضطراری انتشار | تنظیمات سیستم (بدون خاموش‌کردن بات) |
| 🧪 حالت آزمایشی | کانال‌ها → 🎛 حالت آزمایشی |

اعلان ارسال جدید و پرداخت جدید از قبل وجود داشتند و حالا با کلید مستقل در داشبورد روشن/خاموش می‌شوند
(`ADMIN_NOTIFY_NEW_SUBMISSION` / `ADMIN_NOTIFY_NEW_PAYMENT` / `ADMIN_NOTIFY_PUBLISH_ERROR`).
این کلیدها با `ensureV014Settings_()` در اولین وبهوک به‌صورت خودکار برای نصب‌های موجود ساخته می‌شوند.

## ۷) استاندارد دکمه‌ها

| نوع | رفتار |
|---|---|
| تغییر حالت | گزینهٔ فعال با «✅» |
| روشن/خاموش | تیک 🟢/⚪️ و متن «روشن/خاموش» |
| انتخاب چندگانه | ⬜️/✅ و دکمهٔ تأیید |
| انتخاب زمان/تعداد | گزینه‌های آماده + ورودی دلخواه |
| تغییر متن | نمایش مقدار فعلی + راهنما + «❌ لغو» |
| حذف | تأیید دوباره |
| انتشار عمومی | پیش‌نمایش + تأیید نهایی |
| بازگشت | در همهٔ صفحه‌ها |
| فهرست بلند | صفحه‌بندی (◀️ ۱/۵ ▶️) |

ورودی متنی فقط برای موارد واقعاً متنی (شناسهٔ کانال، شمارهٔ کارت، متن تبلیغ، فوتر، نام دلخواه پلن) با
راهنما، اعتبارسنجی و دکمهٔ لغو استفاده می‌شود.

## ۸) سازگاری و استقرار

- بدون تغییر ساختار شیت‌ها؛ `ensureV014Settings_()` فقط کلیدهای تازه را **اگر خالی باشند** می‌سازد.
- همهٔ کال‌بک‌های جدید با پیشوند `d:` و آرگومان‌های کوتاه ASCII هستند (سقف ۶۴ بایت تلگرام).
- دسترسی هر دسته با همان نقش‌های موجود سنجیده می‌شود (`adminPermissionForCallback_` برای `d:` گسترش یافته).
- نشست‌های موجود مدیر (فعال/منقضی) دست‌نخورده‌اند؛ «❌ لغو» و دکمه‌های منوی قدیمی هم به داشبورد برمی‌گردند.
- استقرار: کد `code.js` را در Apps Script جای‌گذاری/به‌روزرسانی کن و یک‌بار `/start` بزن؛ نیازی به اجرای دستی
  `setupProject` نیست. برای دسترسی به کلیدهای تازهٔ اعلان، اولین وبهوک آن‌ها را می‌سازد.
